# VoiceNotepad — голосовой блокнот для наших мам ❤️

Простой голосовой блокнот, изначально сделанный для iPhone и наших любимых мам.

Идея простая: не нужно разбираться в сложных приложениях, создавать аккаунты, искать нужные кнопки или печатать длинный текст на телефоне.

Открыла блокнот, нажала на микрофон, сказала — готово.

## Что это

VoiceNotepad — небольшое **PWA-приложение (Progressive Web App)**, которое можно добавить на домашний экран iPhone и использовать практически как обычное приложение.

Оно сделано с упором на максимально простой интерфейс и голосовой ввод.

Никаких аккаунтов, папок, тегов, регистраций и десятков настроек.

Только блокнот и заметки.

## Возможности

- добавление записей голосом;
- распознавание русской речи;
- добавление записей вручную;
- редактирование существующих записей;
- отметка выполненных дел;
- удаление записей с возможностью отмены;
- сохранение времени создания записи;
- резервное копирование записей;
- восстановление записей из резервной копии;
- установка на домашний экран iPhone как PWA;
- работа интерфейса без подключения к интернету.

## Как пользоваться

Нажмите на кнопку микрофона и скажите то, что нужно запомнить.

После распознавания речи текст появится в списке.

Запись можно:

- отметить выполненной;
- нажать на текст и отредактировать;
- удалить;
- восстановить сразу после случайного удаления.

Если говорить неудобно, новую запись всегда можно добавить вручную кнопкой **«+»**.

## Установка на iPhone

VoiceNotepad не нужно устанавливать из App Store.

Откройте приложение в Safari, нажмите **«Поделиться» → «На экран Домой»**.

После этого VoiceNotepad появится на домашнем экране и будет запускаться как отдельное приложение.

## Хранение данных

Записи сохраняются локально на устройстве.

Для переноса данных или резервного копирования можно сохранить записи в файл, а затем восстановить их из него.
